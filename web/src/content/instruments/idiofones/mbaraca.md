# Mbaracá

> Nome dado pelo Padre Montoya para o maracá "1.1.2.1.3." (HORNBOSTEL; SACHS, 1914)

Mbaracá s.m. como afirma Gondim (apud SINZIG, 1976, p. 361) "o Padre Montoya escreve desta maneira o maracá". Ver maracá
